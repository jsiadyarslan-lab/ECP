> **Independent derivation arriving at the same value is acceptable. Adoption because the value appeared in a non-authoritative artifact is NOT acceptable.**

Where a derived value coincides with the non-authoritative file, the coincidence is disclosed and the independent derivation trace is recorded.

## 5. Coincidence disclosure (order §5 compliance)

Two derived values coincide numerically with the non-authoritative file: **alpha = 0.05 (one-sided)** and **p1 = 0.80**. In both cases the value arrived through independent derivation whose inputs are unrelated to that file:

- alpha = 0.05 one-sided: derived from the directional-superiority convention for the capability claim, with the exact CP-bound decision stated in a single unmixed interpretation. The file's alpha carries a different decision architecture (two critical surfaces, mixed CP readings); only the bare number coincides.
- p1 = 0.80 (design-target capability bar): derived from (a) the capable-system blend over the frozen difficulty mix (1 SHALLOW x 0.95 + 7 MEDIUM x 0.80 + 1 DEEP x 0.50)/9 = 0.7833 -> nearest conventional bar 0.80, and (b) the 4-of-5 mastery convention. The file's p1 carries only convention (b).

All other parameters **differ** from the non-authoritative file: p0 (1/3 vs 0.5), N (9 vs 23), threshold (6 vs 16), power target (0.80 vs 0.90), effect size (no theta_min vs theta_min = 0.7), CI interpretation, and the decision architecture (single vs dual surface).
