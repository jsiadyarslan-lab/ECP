# Public Provenance Metadata Boundary

This directory contains **public provenance metadata only** for external artifacts. It does not contain case artifacts, case bodies, private review material, formal reasoning, expected answers, derivations, sidecars, or qualification inputs.

The public ECP repository is distinct from the private M3 review corpus:

```text
ECP public repository != private M3 review corpus
```

The M3 artifact referenced here was recovered from JARVIS and remains in the private/local review area. It is not represented as a historical ECP artifact. This boundary records only its external source identity, integrity metadata, and recovery status.

Qualification, registration, execution, and model calls remain outside the scope of this boundary.
